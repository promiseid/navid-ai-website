# نصب قالب NAVIDAI Premium 2.0

این نسخه یک قالب مستقل وردپرس است. برای نصب در Local، فایل ZIP قالب را از بسته انتشار دریافت کنید و در پیشخوان **نمایش ← پوسته‌ها ← افزودن تازه ← بارگذاری پوسته** وارد کنید. بعد از نصب، قالب را فعال کنید و کش مرورگر را پاک کنید.

نسخه استاتیک سایت: https://promiseid.github.io/navid-ai-website/navidai/

توجه: GitHub Pages وردپرس، PHP و پایگاه‌داده را اجرا نمی‌کند.
