# Navid AI Studio – WordPress Theme

قالب فارسی، واکنش‌گرا، راست‌به‌چپ و بدون وابستگی به CDN.

## نصب در وردپرس Local

1. در WordPress Admin به **نمایش → پوسته‌ها → افزودن پوسته تازه → بارگذاری پوسته** بروید.
2. فایل `navidai-studio-wordpress.zip` را انتخاب کنید و «نصب» و سپس «فعال‌کردن» را بزنید.
3. در **نمایش → سفارشی‌سازی → تنظیمات صفحه اصلی Navid AI** توضیح کوتاه و نشانی گیت‌هاب را تغییر دهید.
4. اگر صفحه اصلی سفارشی فعال نشد، به **تنظیمات → خواندن** بروید و «آخرین نوشته‌ها» را به عنوان صفحه نخست بگذارید، یا یک برگه را به عنوان صفحه اصلی برگزینید.

## نکات
- صفحه نخست با `front-page.php` نمایش داده می‌شود.
- صفحات داخلی، نوشته‌ها و فهرست وبلاگ پشتیبانی می‌شوند.
- لینک‌های ناوبری صفحه اصلی در قالب تعریف شده‌اند؛ منوی قابل ثبت وردپرس برای توسعه‌های بعدی آماده است.
- فرم ارسال پیام به سرور وجود ندارد؛ لینک ارتباط به گیت‌هاب منتقل می‌شود.
- قالب از داده‌های شخصی و اطلاعات ورود استفاده نمی‌کند.
