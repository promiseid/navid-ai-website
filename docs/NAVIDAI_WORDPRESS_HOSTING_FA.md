# NAVIDAI — وردپرس رایگان + گیت‌هاب

## وضعیت فعلی
- مخزن GitHub عمومی: https://github.com/promiseid/navid-ai-website
- قالب آماده وردپرس: `themes/navidai-premium/`
- سایت نمایشی GitHub Pages: https://promiseid.github.io/navid-ai-website/navidai/
- **وردپرس عمومی هنوز نصب نشده است.** برای ساخت حساب رایگان هاست، اقدام مالک حساب لازم است.
- گردش‌کار انتشار قالب در `.github/workflows/deploy-navidai-wordpress.yml` آماده است ولی به صورت پیش‌فرض غیرفعال است.

## مرحله ۱ — ساخت هاست
1. به https://www.infinityfree.com/ بروید، ثبت‌نام کنید و یک حساب میزبانی رایگان ایجاد کنید.
2. یک زیردامنه رایگان برای NAVIDAI انتخاب کنید. نام نهایی به موجود بودن زیردامنه بستگی دارد.
3. در کنترل‌پنل از Softaculous گزینه WordPress را نصب کنید. مسیر نصب را خالی بگذارید تا وردپرس در ریشه دامنه باشد.
4. HTTPS / SSL را فعال کنید و باز شدن `https://YOUR-SUBDOMAIN/wp-admin/` را بررسی کنید.
5. از پیشخوان وردپرس به بخش «نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته» بروید و ZIP قالب NAVIDAI Premium را نصب و فعال کنید.
6. وقتی سایت باز شد، آدرس دامنه نهایی را ثبت کنید تا لینک‌های سایت و تنظیمات اتصال بررسی شوند.

## مرحله ۲ — اتصال امن گیت‌هاب به هاست (پس از نصب)
فقط زمانی تنظیم کنید که مطمئن شده‌اید وردپرس و پوشه قالب روی هاست ایجاد شده‌اند.

در GitHub، مسیر **Settings → Secrets and variables → Actions**:
- بخش **Secrets**: `NAVIDAI_FTP_SERVER` (آدرس سرور FTP از کنترل‌پنل)، `NAVIDAI_FTP_USERNAME` و `NAVIDAI_FTP_PASSWORD`.
- بخش **Variables**: `NAVIDAI_FTP_THEME_DIR` = مسیر واقعی پوشه قالب روی سرور با `/wp-content/themes/navidai-premium/` در انتها؛ نمونه فقط برای توضیح: `YOUR-SITE/htdocs/wp-content/themes/navidai-premium/`. مسیر دقیق را از پنل هاست بگیرید.
- بخش **Variables**: `NAVIDAI_WP_DEPLOY_ENABLED` = `true`، تنها پس از بررسی صحت تنظیمات.

از تب Actions گردش‌کار **Deploy NAVIDAI Premium to WordPress** را یک‌بار با `dry_run=true` اجرا و خروجی را بررسی کنید. پس از اطمینان، اجرای دستی با `dry_run=false` را انجام دهید. سپس هر تغییر در پوشه قالب روی شاخه main به صورت خودکار همان پوشه قالب را به هاست منتقل می‌کند.

**نکات امنیتی:** رمز FTP یا اطلاعات دیتابیس را هرگز در مخزن عمومی یا چت منتشر نکنید. آنها فقط باید در GitHub Actions Secrets تنظیم شوند. این گردش‌کار فایل‌های هسته وردپرس، افزونه‌ها، محتوای آپلودشده و دیتابیس را منتقل نمی‌کند. FTP over TLS (Explicit FTPS) استفاده می‌شود و ممکن است در بعضی هاست‌های رایگان نیاز به عیب‌یابی اتصال داشته باشد.

## محدودیت مهم
GitHub Pages نسخه استاتیک را نمایش می‌دهد؛ خود وردپرس و `wp-admin` فقط روی آدرس هاست عمومی اجرا می‌شود. تغییرات مطالب/صفحات/رسانه‌ها از طریق پیشخوان وردپرس در دیتابیس هاست ذخیره می‌شوند و به‌صورت خودکار در GitHub ثبت نمی‌شوند؛ گردش‌کار بالا **فقط قالب** را منتشر می‌کند.
